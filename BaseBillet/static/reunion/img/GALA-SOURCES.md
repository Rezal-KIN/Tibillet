# Assets Gala embarqués

Le logo provient du site public du Gala :
https://galas-am-aix.com/wp-content/uploads/2025/08/Logo-Video-seul-copie.png
Téléchargé le 5 octobre 2026, puis converti en WebP sans perte, sans changement
de dimensions ou de transparence. Il remplace une référence vers un fichier
absent du dépôt et renvoyant HTTP 404 sur l'instance.

La police `../font/dm-serif-text/dm-serif-text.ttf` est DM Serif Text Regular :
https://github.com/google/fonts/blob/main/ofl/dmseriftext/DMSerifText-Regular.ttf
Blob Git vérifié : `a8adbe2a9b66c477841e52fd69c96934263f0873`.
Sa licence originale SIL Open Font License est conservée dans le même dossier.

Les CSS et JavaScript Gala sont désormais dans les sources `BaseBillet/static`
collectées normalement par `collectstatic`. Aucune copie manuelle après le
premier démarrage n'est requise.
