# Auteurs, licences et modifications de ce fork

TiBillet est le travail de ses auteurs originaux, dont la coopérative Code Commun.
Les crédits détaillés sont conservés dans [AUTHORS.md](AUTHORS.md).

Le fork **Rezal-KIN/Tibillet** comporte des modifications et une configuration de
déploiement pour les galas Arts et Métiers. Les personnalisations historiques ont
été importées sous `deploy/` le **21 septembre 2026** (commit `0b7078ea`) ; cette
date est celle de l'import Git, et non une date attribuée à leur écriture initiale.
Les portages QR et les évolutions de déploiement sont datés dans l'historique Git.
L'offre d'accès aux sources et les liens d'interface ont été préparés le
**3 octobre 2026**. Ces modifications sont maintenues par les contributeurs du fork
Rezal-KIN ; cette mention ne transfère pas les droits des auteurs originaux.

Les applications modifiées restent sous **GNU AGPLv3**, dont le texte intégral est
dans [LICENSE](LICENSE). Elles sont fournies sans garantie, dans les limites
autorisées par la loi. Les destinataires peuvent les modifier et les redistribuer
selon cette licence ; aucune condition de financement ou de fusion dans le dépôt
original n'est ajoutée à ces permissions.

## Composants tiers

La licence AGPL du logiciel n'efface pas les licences propres aux bibliothèques,
polices, illustrations et templates. Leurs mentions existantes doivent être
conservées. Le template HTML5 UP Dimension conserve notamment sa licence
[CC BY 3.0](QrcodeCashless/templates/html5up-dimension/LICENSE.txt), ses crédits HTML5 UP
et ses notices. Les polices Luciole, les icônes et les autres assets conservent les
notices présentes dans leurs répertoires et les crédits de `AUTHORS.md`.

L'inventaire des notices effectué pour cette correction est décrit dans
[l'audit de l'offre de sources](deploy/docs/operations/agpl-source-offer.md).
Il ne constitue pas une attribution de droits sur les images téléversées par les
organisateurs ou une vérification exhaustive de toutes les dépendances transitives.
